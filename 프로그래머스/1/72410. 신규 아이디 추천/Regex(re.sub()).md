# Python 정규표현식(Regex)으로 문자열 정리하기

`re.sub()`를 사용해 **허용되지 않는 문자 제거**와 **연속된 마침표 축약**을 처리하는 방법

```python
import re

answer = re.sub(r'[^a-z0-9._-]', '', answer)  # 1. 허용되지 않는 문자 제거
answer = re.sub(r'\.+', '.', answer)          # 2. 연속된 마침표를 하나로
```

## `re.sub()` 기본 형태

```python
re.sub(패턴, 바꿀_문자열, 원본_문자열)
```

원본 문자열에서 **패턴과 일치하는 부분**을 찾아 **바꿀 문자열**로 교체한다.

---

## 1. 허용되지 않는 문자 제거하기

```python
answer = re.sub(r'[^a-z0-9._-]', '', answer)
```

허용된 문자(소문자, 숫자, `.`, `_`, `-`)만 남기고 나머지는 전부 제거한다.

| 코드 | 의미 |
| --- | --- |
| `re.sub()` | 패턴에 일치하는 부분을 다른 문자열로 교체 |
| `r'...'` | 정규표현식 패턴을 나타내는 raw 문자열 |
| `[^...]` | 대괄호 안의 문자들을 **제외한** 나머지 문자 |
| `a-z` | 소문자 a부터 z까지 |
| `0-9` | 숫자 0부터 9까지 |
| `._-` | 마침표, 밑줄, 빼기 기호 |
| `''` | 빈 문자열로 교체 → 즉, 제거 |
| `answer` | 처리할 원본 문자열 |

즉, `r'[^a-z0-9._-]'`는 **소문자·숫자·마침표·밑줄·빼기 기호가 아닌 문자**를 찾아낸다.

### 예시

```python
answer = "Abc!@#123_.-"

answer = re.sub(r'[^a-z0-9._-]', '', answer)

print(answer)
# bc123_.-
```

---

## 2. 연속된 마침표를 하나로 바꾸기

```python
answer = re.sub(r'\.+', '.', answer)
```

연속으로 나오는 마침표를 하나의 마침표로 바꾼다.

| 정규표현식 | 의미 |
| --- | --- |
| `\.` | 마침표 문자 `.` 자체 |
| `+` | 바로 앞의 패턴이 1번 이상 반복됨 |
| `\.+` | 마침표가 1개 이상 연속된 부분 |

### 왜 `\.`처럼 역슬래시를 붙일까?

정규표현식에서 그냥 `.`은 **거의 모든 문자 하나**를 의미하는 특수 기호이다.
마침표 문자 자체를 찾으려면 `\.`으로 이스케이프해야 한다.

### 예시

```python
answer = "a...b....c"

answer = re.sub(r'\.+', '.', answer)

print(answer)
# a.b.c
```

`...`과 `....` 모두 하나의 `.`으로 바꾼다.

---

## 3. 두 코드 비교

| 코드 | 역할 | 입력 | 결과 |
| --- | --- | --- | --- |
| `re.sub(r'[^a-z0-9._-]', '', answer)` | 허용되지 않는 문자를 제거 | `a!b@c` | `abc` |
| `re.sub(r'\.+', '.', answer)` | 연속된 마침표를 하나로 축약 | `a...b` | `a.b` |

### 핵심 요약

- `[^...]` → **허용되지 않는 문자**를 찾는다.
- `\.+` → **연속된 마침표**를 찾는다.
